# ✨ LuxeAtlir

**LuxeAtlir** is a modern luxury fashion e-commerce website designed to deliver a premium and elegant online shopping experience.

The website combines a sophisticated visual design with a responsive interface, product discovery, shopping functionality, and a streamlined checkout experience.

## 🌐 Live Website

**LuxeAtlir:** https://luxeatlir.netlify.app/

## 📌 About the Project

LuxeAtlir is a fashion-focused e-commerce web application created with a premium and minimal design approach.

The project is designed to provide customers with an easy way to:

* Explore fashion products
* View product details
* Add products to the shopping cart
* Manage cart items
* Proceed through checkout
* Place and track orders
* Browse the store across desktop, tablet, and mobile devices

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Pradyum8452/luxeatlir.git
```

### 2. Navigate to the project

```bash
cd luxeatlir
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

## 🏗️ Build for Production

Create a production build using:

```bash
npm run build
```

The production files will be generated in:

```text
dist/
```

To preview the production build locally:

```bash
npm run preview
```

## ☁️ Deployment
